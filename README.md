# Luck Points source package

The installable Foundry VTT module is located in `luck-points/`.

Run validation with:

```text
npm run check
```

Localization guidance is available in `luck-points/docs/LOCALIZATION.md`.

Build deterministic release archives using:

```text
python3 tools/release.py --output /path/to/output
```

The source ZIP includes the full `.git` history and release tags.
